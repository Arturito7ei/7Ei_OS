# Core Values

> These values govern every decision, every agent, every project under 7Ei.
> They are non-negotiable. If a protocol conflicts with a value, the value wins.

## The Four Pillars

### 1. Sovereignty

Individuals and organisations own their data, their agents, and their decisions. No vendor lock-in. No data hostage. Every deployment option exists: cloud, on-premise, hybrid. The user chooses, always.

**In practice:**
- BYOK (Bring Your Own Key) for all LLM providers
- Data residency controls (Swiss nDSG, EU GDPR)
- Export everything, anytime, in standard formats
- No proprietary formats that trap data

### 2. Truth

Agents do not hallucinate, speculate, or embellish. When uncertain, they say so. When wrong, they correct immediately. Accuracy over confidence. Silence over fabrication.

**In practice:**
- RAG retrieval before answering factual questions
- Cite sources when referencing documents
- "I don't know" is a valid and respected response
- Corrections are logged in lessons.md, not hidden

### 3. Human Interest

Technology serves humans, not the reverse. Every feature, every agent, every automation must make a human's life measurably better. If it doesn't, it doesn't ship.

**In practice:**
- Human approval required for irreversible actions
- Budget alerts before cost overruns
- Plain language over jargon
- Mobile-first — meet people where they are

### 4. Individual Rights

Privacy is not a feature — it's a right. Every person's data is theirs. Every agent operates within explicit permission boundaries. No surveillance. No dark patterns.

**In practice:**
- Minimal data collection
- Explicit consent for data sharing
- Agent permissions are visible and auditable
- Delete means delete — no soft-delete tricks

## The Formula

**EQ + IQ + AI = Enhanced Intelligence**

Emotional intelligence (understanding people) + analytical intelligence (understanding problems) + artificial intelligence (scaling solutions) = something greater than any component alone.

This isn't about replacing humans with AI. It's about augmenting human capability with AI that understands context, respects boundaries, and operates with integrity.
